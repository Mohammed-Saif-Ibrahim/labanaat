# @labanaat/ui

Accessible, composable, type-safe React components built on design tokens.

## Install

```bash
npm install @labanaat/ui
```

```tsx
import "@labanaat/ui/styles.css";
import { Button } from "@labanaat/ui/button";

export function Example() {
  return <Button variant="primary">Continue</Button>;
}
```

See the full docs site at `apps/landing/app/docs` (introduction, installation, theming,
accessibility, localization, and per-component references), served at `/docs`
alongside the marketing site — or read the source MDX directly in this repo.
