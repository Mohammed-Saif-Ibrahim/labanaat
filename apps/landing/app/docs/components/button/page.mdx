# Button

The foundational interactive element. Composable via `asChild`, with built-in loading and icon-slot support.

<LiveDemo code={`<Button>Save changes</Button>`} />

<LiveDemo code={`<div className="ui-flex ui-flex-wrap ui-gap-2">

    <Button variant="danger">Danger</Button>
    <Button variant="link">Link</Button>
  </div>`} />

## Sizes

<LiveDemo code={`<div className="ui-flex ui-items-center ui-gap-2">

    <Button size="md">Medium</Button>
    <Button size="lg">Large</Button>

## Loading state

<LiveDemo code={`<Button isLoading>Saving…</Button>`} />

## Composition with asChild

Renders as the child element instead of a `<button>`, merging button styles onto it — useful for wrapping a `<Link>` or `<a>`.

<LiveDemo code={`<Button asChild><a href="#">Read the docs</a></Button>`} />

