## Installation

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from "@labanaat/ui/tabs";
```

## Props

`Tabs` accepts Radix's `Tabs.Root` props (`value`/`defaultValue`/`onValueChange`, `orientation`). `TabsList`, `TabsTrigger` (`value`, `disabled`), and `TabsContent` (`value`) follow Radix's Tabs API directly.
