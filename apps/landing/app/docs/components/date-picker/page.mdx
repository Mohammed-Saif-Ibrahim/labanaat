# DatePicker

Built on the native `<input type="date">` rather than a custom calendar grid — a deliberate trade-off. The native control gets correct keyboard input, locale-aware formatting, and mobile date wheels for free, at the cost of custom visual styling. A fully custom `DateRangePicker` is planned as a follow-up — see the [roadmap](/docs/introduction).

## Installation

```tsx
import { DatePicker } from "@labanaat/ui/date-picker";
```
