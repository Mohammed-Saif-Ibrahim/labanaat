# Accordion

Collapsible sections built on Radix's Accordion primitive for correct single/multiple expansion modes and arrow-key navigation between triggers.

## Installation

```tsx
import { Accordion, AccordionItem, AccordionTrigger, AccordionContent } from "@labanaat/ui/accordion";
```

## Props

`type="single"` allows one open item at a time; `type="multiple"` allows several. Pass `collapsible` to allow closing the last open item in single mode. `AccordionItem` requires a unique `value`; the rest follow Radix's Accordion API directly.
